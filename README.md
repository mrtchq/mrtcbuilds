# mrtcbuilds (`mrtc.me`)

Source and live static build for **[mrtc.me](https://mrtc.me)** — *MRTC // T.C. • AI ARCHITECT*.

## Structure

- `index.html` — Live single-file static site served at `https://mrtc.me/` (10-slide interactive horizontal deck, WebAudio 40Hz binaural & synth engine, interactive Chunker quest widget, 2D neural canvas background, and mobile touch/swipe navigation).
- `src/index.html` — Canonical editable source mirror (kept byte-identical to `index.html`).
- `assets/logo.jpg` — Brand mark / avatar asset.

## Deployment

- **Staging:** `/var/www/test.mrtc.me/` (`https://test.mrtc.me`)
- **Production:** `/var/www/mrtc.me/` (`https://mrtc.me`)
